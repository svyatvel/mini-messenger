# Коло — простір для розмов

Вебмесенджер для навчальних груп. Адаптивний сайт працює у браузері, а TypeScript-сервер обробляє запити та зберігає користувачів, розмови й повідомлення у JSON.

## Можливості

- Створення профілів і перемикання між ними.
- Особисті та групові розмови.
- Історія повідомлень із часовими мітками, автоматичним оновленням і JSON-збереженням.
- Пошук повідомлень у розмовах поточного профілю.
- Перевірка імен користувачів, учасників розмов і тексту повідомлень.
- Адаптивний інтерфейс для комп’ютера, планшета та телефона.
- Атомарне збереження JSON, щоб зменшити ризик пошкодження файла під час запису.

## Запуск

Потрібні Node.js 20+ і npm.

```sh
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000). За замовчуванням дані зберігаються у `data/messages.json`.

Для production-запуску:

```sh
npm run build
npm start
```

Порт, мережеву адресу та шлях до файла даних можна задати змінними середовища `PORT`, `HOST` та `DATA_FILE_PATH`. Без змінної `HOST` сервер доступний лише на локальному комп’ютері.

## Безкоштовне демо на Render

Файл `render.yaml` налаштовує безкоштовний вебсервіс. Щоб отримати публічний URL:

1. У Render виберіть **New → Blueprint** та під’єднайте GitHub-репозиторій `svyatvel/mini-messenger`.
2. Підтвердьте створення сервісу `mini-messenger-demo`.
3. Після завершення розгортання відкрийте URL сервісу на домені `onrender.com`.

Безкоштовний план не має постійного диска: сервіс зберігає JSON у тимчасовому каталозі, тому дані можуть зникнути після перезапуску або нового розгортання. Безкоштовний сервіс також може засинати, тож перше відкриття після простою іноді займає більше часу.

**Демо публічне й не має автентифікації:** профілі захищені лише в інтерфейсі, а не паролем. Не використовуйте цей сайт для приватного листування або чутливих даних.

## Перевірка

```sh
npm test
```

Тести перевіряють JSON-збереження, групові розмови, валідацію, пошук і HTTP API вебзастосунку.
