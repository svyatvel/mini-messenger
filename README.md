# Коло — простір для розмов

Повноцінний вебмесенджер для навчальних груп. Адаптивний сайт працює у браузері, а TypeScript-сервер обробляє запити та зберігає користувачів, розмови й повідомлення у JSON.

## Можливості

- Створення профілів і перемикання між ними.
- Особисті та групові розмови.
- Історія повідомлень із часовими мітками, автоматичним оновленням і збереженням між запусками.
- Пошук повідомлень у розмовах поточного профілю.
- Перевірка імен користувачів, учасників розмов і тексту повідомлень.
- Адаптивний інтерфейс для комп’ютера, планшета та телефона.
- Атомарне збереження JSON, щоб зменшити ризик пошкодження файла під час запису.

## Запуск

Потрібні Node.js 20+ і npm.

```sh
npm install
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000). Дані автоматично зберігаються у `data/messages.json`.

Для production-запуску:

```sh
npm run build
npm start
```

Щоб змінити порт, задайте змінну середовища `PORT` перед запуском. Сервер прив’язується до `127.0.0.1`; профілі в цій навчальній версії не захищені паролем і призначені для локального використання.

## Перевірка

```sh
npm test
```

Тести перевіряють JSON-збереження, групові розмови, валідацію, пошук і HTTP API вебзастосунку.
