# Коло — простір для розмов

Вебмесенджер для навчальних груп. Адаптивний сайт працює у браузері, а сервер обробляє запити та зберігає користувачів, розмови й повідомлення.

## Можливості

- Створення профілів і перемикання між ними.
- Особисті та групові розмови.
- Історія повідомлень із часовими мітками та автоматичним оновленням.
- Пошук повідомлень у розмовах поточного профілю.
- Перевірка імен користувачів, учасників розмов і тексту повідомлень.
- Адаптивний інтерфейс для комп’ютера, планшета та телефона.

## Локальний запуск

Потрібні Node.js 20+ і npm.

```sh
npm install
npm run dev
```

Відкрий [http://localhost:3000](http://localhost:3000). Локальний Node.js-сервер зберігає дані у `data/messages.json`.

## Публікація на Cloudflare Workers + D1

Cloudflare Workers публікує сайт за постійною HTTPS-адресою `workers.dev`, а D1 зберігає дані у базі, незалежній від перезапусків Worker.

1. Створи акаунт Cloudflare і ввімкни для нього `workers.dev`. Вимоги перевірки облікового запису можуть відрізнятися залежно від акаунта та регіону.
2. У терміналі з кореня проєкту виконай:

```sh
npm install
npx wrangler login
npm run deploy:cloudflare
npm run db:migrate:remote
```

Під час першого розгортання Wrangler створить Worker і D1 для конфігурації. Після виконання міграції URL сервісу буде показано в терміналі; зазвичай він має вигляд `https://mini-messenger-demo.<твій-workers.dev-піддомен>.workers.dev`.

Wrangler збереже ID віддаленої бази у `wrangler.jsonc`. Цей ID не є секретом: закоміть і запуш його, якщо хочеш розгортати наступні версії автоматично з GitHub. API-токени до репозиторію не додавай.

Щоб перевірити Cloudflare-версію локально:

```sh
npm run db:migrate:local
npm run dev:cloudflare
```

Зміни схеми додавай окремими SQL-файлами до `migrations/`, після чого застосовуй їх командою `npm run db:migrate:remote`.

Щоб публікувати зміни з GitHub автоматично, після початкового розгортання під’єднай репозиторій у Cloudflare **Workers Builds** і вибери гілку `main`. Вкажи `npm run deploy:cloudflare` як команду розгортання. Для початкового налаштування потрібен акаунт Cloudflare і дозвіл під’єднати GitHub-репозиторій.

Workers і D1 мають безкоштовні плани з лімітами — перевір актуальні умови Cloudflare. Не можу гарантувати, що під час реєстрації або перевірки акаунта Cloudflare не попросить платіжну картку.

**Важливо:** застосунок поки не має паролів чи справжньої автентифікації. Будь-хто з доступом до публічного URL може створювати профілі та надсилати повідомлення від імені відомих користувачів. Використовуй сайт як демо, не для приватного листування чи чутливих даних.
